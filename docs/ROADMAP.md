# 로드맵

각 단계는 "학생이 실제로 써볼 수 있는 상태"를 종료 조건으로 한다. 단계 순서는 의존성 순서다: 공압이 캔버스·배선·유체 솔버의 기반을 만들고, 전기가 연동(솔레노이드·리밋 스위치)을 추가하고, 유압은 유체 솔버를 재사용하고, PLC는 전기 I/O 위에 올라간다.

## Phase 0 — 기반 (에디터 뼈대) ✅ 완료 (2026-07-12)

- Vite + React + TS 프로젝트 셋업, `core/` · `ui/` 구조
- 문서 모델 + JSON 직렬화/역직렬화 (스키마 버전 포함)
- 캔버스: 그리드, 팬/줌, 부품 배치·이동·회전·삭제, 직교 배선, 스냅
- 부품 정의 레지스트리 + 속성 패널 자동 생성
- 파일 저장/불러오기 (.json 다운로드/업로드)
- undo/redo

**완료 기준**: 더미 부품 두 개를 놓고 배선해 저장→불러오기 왕복이 되는 것.

## Phase 1 — 공압 ✅ 완료 (2026-07-13)

- 공압 부품 라이브러리 (PRD 4.1 전체) + ISO 1219 기호 SVG
- 유체 솔버 + 실린더 적분 + 고정 틱 엔진
- 시뮬레이션 모드: 수동 밸브 클릭 조작, 가압 라인 색상, 밸브 스풀·실린더 애니메이션
- 실행 전 검증 (미연결 포트, 압력원 부재)
- 내장 예제: 기초 공압 회로 5~10종 (단동 실린더 직접 제어, 5/2 밸브 왕복, 속도 제어, 셔틀/2압 논리)

**완료 기준**: 순수 공압 시퀀스(공압 파일럿 방식 A+A-)가 작도·시뮬레이션되는 것.

## Phase 2 — 전기 + 전기공압 연동 ✅ 완료 (2026-07-13)

- 전기 부품 라이브러리 (PRD 4.2) + 사다리형 전기 회로도 영역
- 전기 연결성 솔버, 릴레이/타이머/카운터 상태 기계
- 도메인 연동: 솔레노이드→밸브 전환, 실린더 리밋 스위치→접점
- 내장 예제: 자기유지, 인터록, 타이머 회로, 전기공압 A+B+A-B- (공유압기능사 실기 유형)

**완료 기준**: 공유압기능사 실기 유형의 전기공압 시퀀스 회로가 동작하는 것.

## Phase 3 — 유압 ✅ 완료 (2026-07-13)

- 유압 부품 라이브러리 (PRD 4.3), 유체 솔버에 탱크 귀환·중립 센터 타입 반영
- 내장 예제: 유압 기초 회로 (실린더 왕복, 릴리프 압력 유지, 미터인/아웃, 카운터밸런스)

**완료 기준**: 4/3 밸브 + 복동 실린더 유압 회로가 전기 제어로 동작하는 것.

## Phase 4 — PLC 래더 (XG5000 스타일) ✅ 완료 (2026-07-13)

- 래더 모델 + 셀 그리드 에디터 (접점, 코일, TON/CTU 기능블록, 렁 편집)
- 스캔 실행기 + P 디바이스 I/O 매핑 테이블 UI
- 모니터 모드 (통전 오버레이)
- 내장 예제: 자기유지, 타이머 시퀀스, 전기공압 회로의 PLC 치환 예제

**완료 기준**: Phase 2의 릴레이 시퀀스 예제를 PLC 래더로 동일하게 재현할 수 있는 것.

## Phase 5 — 장비 뷰 + 마감 ✅ 완료 (2026-07-13)

- 일러스트 장비 뷰 (프로파일 보드): 공압 우선, 회로도와 스플릿 화면 동기화
- 예제 브라우저 정리 (카테고리: 기초 공압 / 전기공압 / 유압 / PLC / 자격증 유형)
- 성능 점검 (부품 100개 60fps), UI 폴리시(한국어 문자열 정리, 단축키, 인쇄용 회로도 내보내기)

**완료 기준**: 수업 1차시 분량의 데모 시나리오를 처음부터 끝까지 시연 가능한 것.

### 구현 노트 (완료 시점 상태)

- 장비 뷰는 공압/전기 주요 부품 16종의 일러스트 스프라이트 제공, 미등록 부품은 기호로 폴백. 뷰포트를 회로도와 공유해 팬/줌 동기화되며 시뮬레이션 중 스프라이트를 직접 클릭해 조작 가능.
- 예제 17종을 카테고리(공압 기초/전기공압/유압/PLC/자격증 유형)로 분류.
- 성능: 부품 100개 + 배선 100개 회로에서 엔진 평균 틱 시간 5ms 미만 (테스트 상시 검증).
- 인쇄용 SVG 내보내기 지원 (그리드 제거, CSS 변수 인라인).
- 미구현 잔여: 프로파일 보드 배경/장비 배치 자유 이동(장비 뷰는 회로도 좌표 공유), 감압밸브(정량 모델 필요), 유압 모터.

## Phase 6 — 변위단계선도 ✅ 완료 (2026-07-13)

- 시뮬레이션 중 실린더별 위치(0~1)를 시간축으로 기록하는 레코더 (core, React 무관)
- 계단형 선도 차트 패널: 실린더별 트랙(이름표 병기), 실행 시 자동 기록·초기화
- 자격증 실기의 시퀀스 설계 검증(A+B+A−B− 파형 확인)이 목적

**완료 기준**: A+B+A−B− 예제 실행 시 두 실린더의 계단 파형이 순서대로 그려지는 것.

## Phase 7 — 압력 레벨 (준정량 최소 확장) + 감압밸브 + 압력 스위치 ✅ 완료 (2026-07-13)

- 유체 솔버가 가압 전파 시 **압력 레벨(bar 수치)**을 함께 전파 — 수치 해석이 아니라 경로상 최소 레벨 전파(min-cap)로, 논리/상태 기반 결정을 유지하는 최소 확장
- 감압밸브(유압): 통과 시 레벨을 설정값으로 제한
- 압력계: 배관 레벨 수치 표시
- 압력 스위치(공압, PRD 4.1 잔여): 유체 포트 압력이 설정 레벨 이상이면 전기 접점 동작 (유체→전기 연동)

**완료 기준**: 파워유닛(40bar) → 감압밸브(20bar) → 압력계가 20을 표시하고, 압력 스위치로 램프가 켜지는 것.

## Phase 8 — 장비 뷰 자유 배치 ✅ 완료 (2026-07-13)

- 문서에 `equipmentLayout`(부품별 장비 뷰 좌표) 추가 — schemaVersion 2 + 마이그레이션
- 장비 뷰에서 스프라이트 드래그로 자유 배치 (편집 모드), 배치 초기화 버튼
- 호스/배선은 이동된 포트 위치 기준으로 재라우팅

**완료 기준**: 장비 뷰에서 부품을 옮겨 저장→불러오기 후 배치가 유지되는 것.

## Phase 9 — PWA + 로컬 저장소 (백엔드 준비) ✅ 완료 (2026-07-13)

- PWA: 매니페스트 + 서비스 워커(정적 자산 캐시)로 오프라인 실행, 설치 가능
- 저장소 어댑터 인터페이스(list/save/load/delete) + 브라우저(localStorage) 구현 — 파일 없이 회로 저장/열기
- **실제 서버(계정·클라우드·과제 배포)는 "백엔드 없음" 고정 결정에 저촉되므로 사용자 확인 전 착수 금지.** 어댑터 인터페이스가 향후 REST 구현의 접점.

**완료 기준**: 브라우저 저장/열기가 동작하고, 프로덕션 빌드가 오프라인에서 로드되는 것.

## Phase 10 — i18n 기반 + 유압 모터 ✅ 완료 (2026-07-13)

- 문자열 리소스 모듈(t(key), ko/en 사전) + 언어 전환 토글 — UI 크롬(툴바·패널·상태바) 우선 적용, 부품·예제 이름은 후속(한국어 유지)
- 유압 모터: 액추에이터 behavior 확장(정/역회전), 기호 회전 애니메이션

**완료 기준**: 언어 토글로 UI 크롬이 영/한 전환되고, 유압 모터가 밸브 방향에 따라 회전 방향을 바꾸는 것.

## 후순위 후보 (미확정)

- 과제 모드 + 자동 검증 (요구 시퀀스 충족 판정, 채점)
- 부품·예제 이름 영어 번역 (i18n 2차)
- 백엔드 서버 구현 (Phase 9 어댑터 이후, 사용자 결정 필요)
