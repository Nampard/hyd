# PRD — 공압·유압·전기·PLC 교육용 시뮬레이션

## 1. 목표

학생이 브라우저에서 공압/유압/전기/PLC 회로를 **교육용 표준 스타일 기호로 작도**하고, 즉시 **시뮬레이션으로 동작을 확인**하며, 회로도와 나란히 표시되는 **일러스트 실습장비 뷰**로 기호와 실물의 대응을 학습할 수 있게 한다.

교육 효과의 핵심 루프: **작도 → 실행 → 관찰 → 수정**. 실제 실습장비 없이도(또는 실습 전에) 이 루프를 무한 반복할 수 있어야 한다.

## 2. 대상 사용자

| 사용자 | 시나리오 |
|---|---|
| 특성화고/마이스터고 학생 | 수업 시간에 교사가 준 예제 회로를 열어 관찰하거나, 과제 요구사항에 맞춰 직접 작도 후 시뮬레이션으로 확인 |
| 교사 | 예제 회로 파일(.json) 제작·배포, 수업 중 프로젝터로 동작 시연 |
| 자격증 수험생 | 공유압기능사·설비보전기사 실기 과제 회로(변위단계선도 기반 시퀀스)를 예제로 열어 연습 |

브라우저만 있으면 실행되어야 한다 (학교 PC, 설치 권한 없음, 오프라인 캐시 가능하면 우수).

## 3. 유스케이스 (MVP)

1. **회로 작도**: 팔레트에서 부품을 캔버스로 드래그 → 포트끼리 배선/배관 연결 → 부품 속성 편집(예: 밸브 조작 방식, 타이머 설정값)
2. **시뮬레이션 실행**: 실행 버튼 → 회로에 압력/전원 인가 → 사용자가 푸시버튼·수동 밸브를 클릭 조작 → 실린더 동작, 램프 점등 등을 애니메이션으로 관찰
3. **전기공압 연동**: 전기 회로의 솔레노이드가 공압 밸브를 전환, 실린더의 리밋 스위치가 전기 접점을 동작 — 자격증 실기의 핵심 패턴 (A+B+A-B- 등 시퀀스)
4. **PLC 제어**: 교육용 래더(LD, XG5000 표기 관례 참고)를 작성하고 P 디바이스를 회로의 입출력(버튼, 솔레노이드)에 매핑하여 스캔 시뮬레이션
5. **장비 뷰 학습**: 회로도 옆에 프로파일 보드형 일러스트 장비 화면을 띄워, 회로도 기호와 장비 실물 그림이 같은 상태로 함께 동작하는 것을 관찰
6. **저장/불러오기**: 회로 전체(작도 + 속성 + PLC 프로그램)를 .json 파일로 다운로드/업로드
7. **예제 라이브러리**: 앱 내장 예제(기초 회로 ~ 자격증 기출 유형)를 카테고리별로 열람

## 4. 도메인별 컴포넌트 목록 (MVP)

### 4.1 공압 (1차 구현)

- **동력원**: 공압원(컴프레서+탱크 단순화), 서비스 유닛(FRL)
- **밸브**: 3/2·5/2·5/3 방향제어밸브 — 조작 방식 조합(수동 푸시버튼/레버, 롤러 리밋, 솔레노이드 편측/양측, 공압 파일럿, 스프링 복귀/디텐트)
- **실린더**: 단동, 복동 (스트로크·리밋 스위치 위치 속성)
- **유량/논리**: 속도제어밸브(스로틀+체크, 미터인/미터아웃), 셔틀밸브(OR), 2압밸브(AND), 급속배기밸브
- **기타**: 압력 스위치, 소음기, T 분기, 배관(라인)

### 4.2 전기 — 시퀀스 제어 (2차)

- **전원**: 24V/0V 수직 레일 (사다리형 전기 회로도)
- **입력**: 푸시버튼(a/b접점), 셀렉터 스위치, 리밋 스위치(a/b접점, 실린더와 연동), 압력 스위치 접점
- **제어**: 릴레이(코일 + a/b접점 다수), 온딜레이/오프딜레이 타이머, 카운터
- **출력**: 솔레노이드(공압 밸브와 연동), 램프, 부저

### 4.3 유압 (3차)

- **동력원**: 유압 파워유닛(펌프+탱크+릴리프밸브 일체), 개별 릴리프밸브
- **밸브**: 4/2·4/3 방향제어밸브(중립 위치 타입: 클로즈드/탠덤/오픈 센터), 체크밸브, 파일럿 조작 체크밸브, 감압밸브, 유량조절밸브
- **압력제어 (Phase 15)**: 압력 시퀀스 밸브(내부 파일럿 + 체크 내장), 카운터밸런스 밸브(외부 파일럿 + 체크 내장), 어큐뮬레이터. 파일럿 압력이 설정압 이상이면 열리는 같은 규칙(`pressure-pilot-valve`)이고, 한번 열리면 파일럿이 무압이 될 때까지 유지된다(히스테리시스)
- **액추에이터**: 복동 유압 실린더, (선택) 유압 모터. 실린더의 `loadPressure`(부하압, 기본 0 = 사용 안 함)를 설정하면 운동 중 공급 유로 압력이 그 값으로 제한되고 행정 완료 시 소스 압력까지 상승한다 — 압력 시퀀스 회로 학습용 (Phase 15)
- **기타**: 압력계, 탱크 귀환 라인

### 4.4 PLC 래더 — 교육용 LD, XG5000 표기 관례 참고 (4차)

- **디바이스**: P(입출력), M(내부 릴레이), T(타이머), C(카운터). D(데이터 디바이스)와 MOV·비교 명령은 후순위 (비트 논리 교육 범위를 벗어나는 워드 연산이므로 MVP 제외 — codex-review H3 정합)
- **명령**: LOAD/LOADB(평상시닫힘), 음변환(N) 접점, AND/OR 계열, OUT, SET/RST, TON, TOFF, CTU, CTD. 점멸 특수릴레이 _T1S/_T2S(1초/2초 클록) 내장
- **에디터**: 셀 그리드 기반 래더 작성(XG5000 관례의 접점·코일 표기), 렁 단위 편집
- **연동**: P 디바이스 ↔ 회로 부품(버튼, 리밋 스위치 → 입력 / 솔레노이드, 램프 → 출력) 매핑 테이블
- **모니터링**: 시뮬레이션 중 래더 위에 통전 상태 표시 (XG5000 모니터 모드처럼)

### 4.5 자동화설비 기능사 스테이션 (Phase 14)

특정 제조사 장비의 모델이 아니라, 자격증 실기의 일반적 컨베이어 분류 공정을 교육용으로 독자 단순화한 것이다. (상표·비제휴 고지는 README·ASSET_PROVENANCE 참조)

- **부품**: `auto.automation-station` 1종 (통짜 스테이션 — 워크피스 흐름을 내부 상태기계로 캡슐화. 구버전 식별자 `auto.mps-station`은 스키마 v5 마이그레이션으로 자동 변환)
- **구성/공정 순서**: 매거진(중력 공급) → A실린더(양솔) 공급 → B실린더+드릴 가공 → C실린더 이송 → **컨베이어 초입에서 용량형/유도형 재질 판별** → 포토센서 통과 → D실린더 분기 배출(배출박스)/통과(저장박스), 램프 3, PB 4. (판별 센서는 실기 배치도처럼 컨베이어 초입에 위치 — A 공급 직후가 아님)
- **I/O 26점(입력 16 + 출력 10)**: 입력 P00000~F(16진 비트 어드레스, 16점), 출력 P00010~19(10점) — ioMap `channel`(스키마 v4)로 부품 하나에 다점 매핑
- **원칙**: 설비는 물리만 시뮬레이션(액추에이터는 P출력 반응, 센서는 P입력 생성) — 제어 로직은 전부 학습자의 래더. A 양솔은 5/2 임펄스(스풀 메모리)로 펄스 후 종단 이동. 매거진 물품(금속/비금속)은 속성에서 순서 설정
- **표기**: 회로도는 단자대 블록, 작동·애니메이션은 장비 뷰

## 5. 시뮬레이션 요구사항 (논리/상태 기반)

- **전기**: 24V 레일에서 0V 레일까지 닫힌 접점을 통한 연결성으로 코일·램프의 통전 판정. 통전된 도선은 색상 강조.
- **공압/유압**: 압력원에서 열린 밸브 경로를 따라 압력 상태(가압/배기)를 전파. 정량 수치 계산은 하지 않되, 실린더 속도는 속도제어밸브 개도 속성으로 상대 조절 가능.
- **실린더 운동**: 시간 기반으로 위치를 적분(고정 틱). 위치가 리밋 스위치 설정점을 지나면 해당 전기 접점 상태 변경.
- **PLC 스캔**: 입력 이미지 갱신 → 래더 좌→우, 위→아래 평가 → 출력 이미지 반영. 스캔은 시뮬레이션 틱과 동기.
- **애니메이션**: ISO 기호 자체가 상태를 표현(밸브 스풀 위치 전환, 실린더 로드 이동, 가압 라인 색상, 접점 개폐). 장비 뷰도 동일 상태를 일러스트로 표현.
- **조작**: 시뮬레이션 중 사용자가 클릭으로 푸시버튼(누름/유지), 레버, 셀렉터를 조작.
- **검증 피드백**: 실행 전 기본 검사 — 미연결 포트, 압력원/전원 없음, 포트 타입 불일치(전기선↔공압관) 경고.

## 6. 비기능 요구사항

- **기호 표기**: 공압·유압 기호는 ISO 1219-1/KS B 0054에서 통용되는 관례를 참고한 교육용 독자 단순화 작도(적합성 미인증 — 정식 대조는 ASSET_PROVENANCE 참조). 전기 기호는 국내 시퀀스 교육 관례의 단순화 표기(IEC 60617 적합성 미검증). "표준 준수"를 완료 사실로 주장하지 않는다.
- **성능**: 부품 100개 수준 회로에서 60fps 애니메이션, 시뮬레이션 틱 지연 없음.
- **한국어 UI** 기본. 문자열 리소스는 분리해 두어 향후 다국어 여지.
- **파일 포맷**: 사람이 읽을 수 있는 JSON, 스키마 버전 필드 포함 (하위 호환 마이그레이션 전제).
- **오프라인**: 정적 호스팅 + 브라우저 캐시로 네트워크 없이 동작 (PWA는 선택).

## 7. 범위 제외 (Non-goals)

- 정량적 유체역학/전기 회로 해석 (전류·전압·유량 수치 계산)
- 3D 장비 렌더링, 실배선 3D 오퍼레이팅
- 실제 PLC 하드웨어 연결, XG5000 파일(.xgp) 호환
- 사용자 계정, 클라우드 저장, 과제 제출 시스템 (아키텍처만 확장 가능하게)
- 자동 채점/과제 검증 엔진 (로드맵 후순위 후보로만 유지)
