# HYD — 공압·유압·전기·PLC 교육용 시뮬레이션

특성화고/마이스터고 수업과 자격증(공유압기능사 등) 실기 대비를 위한 **웹 기반 회로 작도 + 가상 장비 시뮬레이션 소프트웨어**.

**▶ 바로 사용하기: https://nampard.github.io/hyd/** (설치 불필요, 브라우저에서 실행. 첫 방문 후 오프라인 사용 가능)

기존 상용 공유압·전기 실습 시뮬레이션 소프트웨어(회로도 중심 공학 시뮬레이션, 가상 실습장비 오퍼레이팅)의 장점을 참고하되, 브라우저에서 설치 없이 실행되는 독자적인 교육 도구로 개발한다.

## 핵심 결정사항 (2026-07-12 인터뷰)

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹앱 (React + TypeScript + SVG), 서버 없는 프론트엔드 단독 |
| MVP 도메인 | 공압 → 전기(시퀀스 제어) → 유압 → PLC 래더 (4개 모두 MVP 범위) |
| 시뮬레이션 깊이 | 논리/상태 기반 (압력·유량의 정량 해석 없음, 상태 전파 중심) |
| 표현 방식 | 2D 회로도(ISO 1219/KS B 0054 관례를 참고한 교육용 독자 단순화 기호 — 적합성 미인증) + 일러스트 장비 뷰 병행 |
| PLC 스타일 | XG5000(LS산전) 스타일 래더 |
| 저장 방식 | 로컬 JSON 파일 저장/불러오기 |
| 대상 사용자 | 특성화고/마이스터고 학생·교사, 자격증 수험생 |

## 상태

**전 페이즈(0~11) 완료** (2026-07-14). 주요 기능:

- **후속 페이즈(6~10)**: 변위단계선도 패널, 압력 레벨(준정량)·감압밸브·압력 스위치, 장비 뷰 자유 배치(문서 v2), PWA 오프라인·브라우저 저장소, UI 한/영 전환, 유압 모터

- **에디터**: 교육용 단순화 기호 회로 작도(그리드 스냅, 직교 배선, 종류 불일치 거부), 속성 패널 자동 생성, undo/redo, JSON 저장/불러오기, 인쇄용 SVG 내보내기
- **공압**: 부품 20종 (방향제어밸브 수동/롤러/파일럿/솔레노이드, 실린더, 속도제어·셔틀·2압·급속배기·압력 스위치 등), 상태 기반 압력 전파 시뮬레이션, 기호 애니메이션
- **전기**: 시퀀스 제어 부품 12종 (릴레이·타이머·카운터·리밋스위치·솔레노이드…), 연결성 솔버, 전기공압 연동 (A+B+A−B− 자격증 유형 동작)
- **유압**: 파워유닛, 릴리프(압력 상한 동작)·감압·체크·파일럿체크·유량조절 밸브, 4/2·4/3 밸브(클로즈드/탠덤/오픈 센터), 유압 실린더·모터, 압력계·압력 스위치
- **PLC**: XG5000 스타일 래더 에디터(접점/코일/SET/RST/TON/TOFF/CTU/CTD, OR 분기), 스캔 실행기, P 디바이스 I/O 매핑, 통전 모니터링
- **장비 뷰**: 일러스트 스프라이트 스플릿 화면 (회로도와 상태·뷰포트 동기화, 클릭 조작)
- **실행 모드**: 연속동작 실행 + 구분동작 실행(동작 경계마다 일시정지, 사이클 완료 표시, 변위선도 경계선)
- **예제 18종** (공압 기초/전기공압/유압/PLC/자격증 유형) + 자동 테스트 122개 (골든 시나리오·솔버·스캐너·경계 검증)

## 고지

**교육용 논리/상태 시뮬레이션입니다.** 압력·전류의 수치 해석을 하지 않으며(bar 표시는 공급
레벨 전파용 준정량 값), 실제 설비 선정·압력 설정·안전 검증에 사용해서는 안 됩니다.

**기호는 ISO 1219 / KS B 0054 / IEC 60617에서 통용되는 관례를 참고한 교육용 독자
단순화 표기이며, 표준 적합성이 인증된 것이 아닙니다.** 색상·애니메이션·강조는 HYD의
시뮬레이션 표시이지 표준 기호의 일부가 아닙니다.

XG5000은 LS ELECTRIC의 PLC 프로그래밍 소프트웨어 명칭입니다. 본 프로젝트는 교육 목적으로
그 래더 표기 관례를 참고한 **독립 구현**이며, LS ELECTRIC과 무관하고 `.xgp` 등 XG5000
프로젝트 파일과 호환되지 않습니다. 로고 등 상표 자산은 사용하지 않습니다.
