## 이게 뭔가요?

특성화고·마이스터고에서 공유압(공압·유압)·전기 시퀀스 제어·PLC를 배울 때, 실제 실습 장비가 부족하거나 수업 시간이 짧아서 충분히 연습하기 어려운 경우가 많습니다. HYD는 이 문제를 브라우저만으로 해결하려는 프로젝트입니다.

- 화면에 **표준 스타일 기호**(밸브, 실린더, 릴레이, PLC 접점 등)로 회로도를 그립니다.
- **▶ 실행** 버튼을 누르면 그 회로가 실제로 어떻게 동작하는지 애니메이션으로 확인할 수 있습니다.
- 압력·전류 같은 물리량을 정밀 계산하는 공학용 시뮬레이터는 아닙니다. **"가압됐다/안 됐다", "접점이 붙었다/떨어졌다"** 같은 **논리·상태 흐름**을 보여주는 **교육용** 도구입니다.

기존 상용 실습 시뮬레이터(회로 중심 공학 시뮬레이션, 가상 실습장비 조작 등)의 좋은 점을 참고하되, 그 코드나 자산을 가져오지 않고 **처음부터 독자적으로 만들었습니다.** 이 부분의 근거와 검토 기록은 [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md)에 자세히 남겨두었습니다.

| 예제 | 공압 기초·전기공압·유압·PLC·자격증 유형·자동화설비 예제 23종 내장 |

## 인터넷 제한 환경에서의 교육용 로컬 실행

학교 네트워크에서 GitHub 또는 공식 배포 사이트에 접속하기 어렵거나 인터넷을 사용할 수 없는 경우, **교사와 학교는 비상업적 수업 목적으로 이 프로젝트의 변경되지 않은 사본을 학교가 관리하는 기기와 수업에 참여하는 학생의 기기에 복제하여 로컬에서 실행할 수 있습니다.**

수업에 필요한 범위에서 저장소·배포 파일의 다운로드, USB 등 저장매체를 통한 이전, 의존성 설치, 빌드 및 로컬 실행을 허용합니다. 수업 참여자만 접근할 수 있는 학교 내부망에서 실행할 수 있으나, **공개 인터넷 재호스팅, 불특정 다수에 대한 재배포, 유료 제공, 수정본 배포, 코드·자산의 별도 제품 전용은 허용되지 않습니다.** 사본에서 `LICENSE`와 `public/THIRD_PARTY_NOTICES.txt`를 삭제·변경해서는 안 됩니다. 상세한 허용 범위는 [LICENSE](LICENSE)의 "비상업적 교육용 오프라인 실행 허가" 절을 따릅니다.

```bash
npm install      # 의존성 설치 (Node.js 필요, 백엔드·DB 불필요)
npm run dev      # 로컬 실행 — http://localhost:5173
npm run build    # 정적 빌드 생성 (dist/ 를 학교 내부망 웹서버에 올려도 됩니다)
```

> 위 오프라인 실행 허가를 넘어서는 소스 수정·재배포·개발 기여는 저작자의 사전 서면 동의가 필요합니다([라이선스](#라이선스) 참고). `npm test`는 개발·검증용입니다.

## 중요한 고지사항

**이 소프트웨어는 교육용 논리/상태 시뮬레이션입니다.** 압력·전류의 수치를 정밀하게 계산하지 않으며(화면에 나오는 bar 수치는 압력 전파를 보여주기 위한 근사값입니다), **실제 설비를 선정하거나 압력을 설정하거나 안전을 검증하는 용도로 사용해서는 안 됩니다.**

**회로 기호는 ISO 1219 / KS B 0054 / IEC 60617 등에서 통용되는 표기 관례를 참고해 교육용으로 독자적으로 단순화한 것이며, 정식 표준 적합성이 인증된 것은 아닙니다.** 화면의 색상·애니메이션·강조 효과는 HYD가 시뮬레이션 상태를 보여주기 위해 추가한 것으로, 표준 기호 자체의 일부가 아닙니다.

**XG5000**은 LS ELECTRIC의 PLC 프로그래밍 소프트웨어 이름입니다. 이 프로젝트는 교육 목적으로 그 래더 표기 관례만 참고해 **독립적으로 구현**했으며, LS ELECTRIC과는 무관합니다. `.xgp` 등 XG5000 프로젝트 파일과 호환되지 않고, 로고 등 상표 자산도 사용하지 않습니다.

**자동화설비 스테이션**은 자동화설비 기능사(구 생산자동화 기능사) 실기의 일반적인 컨베이어 분류 공정을 교육용으로 **독자적으로 단순화**한 것입니다. **MPS®는 Festo AG & Co. KG의 등록상표입니다. HYD는 Festo와 제휴·승인·후원 관계가 없으며, Festo MPS® 제품·교재·소프트웨어와 호환되지 않습니다.** 특정 제조사의 실습 장비를 모델·복제한 것이 아니며, 장비 외관·공정 배치는 공개된 자격증 시험 요구사항에서 확인되는 **기능적 구성과 일반적인 공정 순서만 참고**해 도형·코드·화면을 독자적으로 구현했습니다. 공개 시험자료 자체를 재배포하거나 그 이미지·문구·도면을 복제하지 않았으며, 공개 시험자료에 대한 별도의 이용허락이나 공식 제휴를 주장하지 않습니다. (구버전 저장 파일에 남아 있던 내부 식별자 `auto.mps-station`은 파일을 열 때 `auto.automation-station`으로 자동 변환됩니다.)
