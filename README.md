**공유압기능사 등 자격증 실기와 특성화고/마이스터고 수업을 위한, 설치 없이 브라우저에서 바로 쓰는 회로 작도 + 시뮬레이션 웹앱입니다.**

## ▶ 바로 사용해보기

**https://nampard.github.io/hyd/**

설치나 회원가입이 필요 없습니다. 링크를 열면 바로 회로를 그리고 실행해볼 수 있습니다. 한 번 방문한 뒤에는 인터넷이 없어도 계속 쓸 수 있습니다(PWA 오프라인 지원).

## 이게 뭔가요?

특성화고·마이스터고에서 공유압(공압·유압)·전기 시퀀스 제어·PLC를 배울 때, 실제 실습 장비가 부족하거나 수업 시간이 짧아서 충분히 연습하기 어려운 경우가 많습니다. HYD는 이 문제를 브라우저만으로 해결하려는 프로젝트입니다.

- 화면에 **표준 스타일 기호**(밸브, 실린더, 릴레이, PLC 접점 등)로 회로도를 그립니다.
- **▶ 실행** 버튼을 누르면 그 회로가 실제로 어떻게 동작하는지 애니메이션으로 확인할 수 있습니다.
- 압력·전류 같은 물리량을 정밀 계산하는 공학용 시뮬레이터는 아닙니다. **"가압됐다/안 됐다", "접점이 붙었다/떨어졌다"** 같은 **논리·상태 흐름**을 보여주는 **교육용** 도구입니다.

기존 상용 실습 시뮬레이터(회로 중심 공학 시뮬레이션, 가상 실습장비 조작 등)의 좋은 점을 참고하되, 그 코드나 자산을 가져오지 않고 **처음부터 독자적으로 만들었습니다.** 이 부분의 근거와 검토 기록은 [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md)에 자세히 남겨두었습니다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 에디터 | 그리드 스냅, 직교 배선, 부품 배치/회전/삭제, undo/redo, JSON 저장·불러오기, 인쇄용 SVG 내보내기 |
| 공압 (20종) | 방향제어밸브(수동/롤러/파일럿/솔레노이드), 실린더, 속도제어·셔틀·2압·급속배기 밸브, 압력 스위치 등 |
| 유압 (16종) | 파워유닛, 릴리프·감압·체크·파일럿체크·유량조절 밸브, 4/2·4/3 밸브(클로즈드/탠덤/오픈 센터), 실린더·모터 |
| 전기 (12종) | 릴레이·타이머·카운터·리밋스위치·솔레노이드 등, 전기공압 연동(A+B+A−B− 같은 자격증 유형 동작) |
| PLC | 교육용 래더(LD) 에디터 — 접점/코일/SET/RST/TON/TOFF/CTU/CTD, 입출력 매핑(다채널 부품은 채널 지정), 통전 모니터링 (표기는 XG5000(LS ELECTRIC) 관례를 참고했으며 비공식·비제휴) |
| 실행 모드 | 연속동작 실행 + **구분동작 실행**(한 동작이 끝날 때마다 자동 정지, 사이클 완료 표시) |
| 장비 뷰 | 회로도 옆에 일러스트 실습장비 화면을 나란히 띄워 기호와 실물을 대응해서 학습 |
| 자동화설비 | 자동화설비 기능사(구 생산자동화) MPS 스테이션 — 매거진·공급/가공/이송 실린더·재질 판별·컨베이어·분류를 장비 뷰에서 시뮬레이션, I/O 20점을 래더로 제어 |
| 예제 | 공압 기초·전기공압·유압·PLC·자격증 유형·자동화설비 예제 19종 내장 |
| 과제물 | 저장 시 "학습 활동 설명" 문장을 회로 구성에서 자동 작성(수정 가능) — 교사가 파일만 보고도 어떤 학습 활동인지 파악. 이름·학번 전용 필드를 두지 않고 서버로 전송하지 않음(자유 입력란에는 개인정보를 적지 않도록 안내) |
| 품질 | 자동 테스트 190개(핵심 동작 시나리오·솔버·PLC 스캐너·MPS 스테이션·문서 검증) |

## 핵심 결정사항

프로젝트를 시작할 때 정한, 쉽게 바뀌지 않는 방향입니다.

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹앱 (React + TypeScript + SVG), 별도 서버 없이 브라우저에서만 동작 |
| 시뮬레이션 깊이 | 논리/상태 기반 (압력·전류의 정량 해석 없음) |
| 표현 방식 | 2D 회로도(교육용 단순화 기호) + 일러스트 장비 뷰 병행 |
| PLC 스타일 | 교육용 래더(LD) — XG5000(LS산전) 표기 관례 참고, 비공식·비제휴 |
| 저장 방식 | 로컬 JSON 파일 저장/불러오기 (서버에 데이터를 보내지 않음) |
| 대상 사용자 | 특성화고/마이스터고 학생·교사, 자격증 수험생 |

## 개발 환경에서 실행하기

이 저장소를 그대로 실행해보고 싶은 개발자를 위한 안내입니다. (일반 사용자는 위의 배포 링크만으로 충분합니다.)

```bash
git clone https://github.com/Nampard/hyd.git
cd hyd
npm install

npm run dev      # 개발 서버 실행 — http://localhost:5173
npm test         # 자동 테스트 실행
npm run build    # 배포용 빌드 생성
```

Node.js가 설치되어 있어야 합니다. 별도의 데이터베이스나 백엔드 서버는 필요 없습니다.

## 중요한 고지사항

**이 소프트웨어는 교육용 논리/상태 시뮬레이션입니다.** 압력·전류의 수치를 정밀하게 계산하지 않으며(화면에 나오는 bar 수치는 압력 전파를 보여주기 위한 근사값입니다), **실제 설비를 선정하거나 압력을 설정하거나 안전을 검증하는 용도로 사용해서는 안 됩니다.**

**회로 기호는 ISO 1219 / KS B 0054 / IEC 60617 등에서 통용되는 표기 관례를 참고해 교육용으로 독자적으로 단순화한 것이며, 정식 표준 적합성이 인증된 것은 아닙니다.** 화면의 색상·애니메이션·강조 효과는 HYD가 시뮬레이션 상태를 보여주기 위해 추가한 것으로, 표준 기호 자체의 일부가 아닙니다.

**XG5000**은 LS ELECTRIC의 PLC 프로그래밍 소프트웨어 이름입니다. 이 프로젝트는 교육 목적으로 그 래더 표기 관례만 참고해 **독립적으로 구현**했으며, LS ELECTRIC과는 무관합니다. `.xgp` 등 XG5000 프로젝트 파일과 호환되지 않고, 로고 등 상표 자산도 사용하지 않습니다.
