# HYD — 공압·유압·전기·PLC 교육용 시뮬레이터

**메카트로닉스 관련 자격증 실기와 특성화고/마이스터고 수업을 위한, 설치 없이 브라우저에서 바로 쓰는 회로 작도 + 시뮬레이션 웹앱입니다.**

## ▶ 바로 사용해보기

**https://hyd-sim.netlify.app** (기본 주소)

예비 주소: https://nampard.github.io/hyd/ — 같은 버전이 함께 배포됩니다. 일부 통신망에서 GitHub Pages가
"사이트에 연결할 수 없음"으로 간헐적으로 열리지 않는 일이 있어 Netlify 주소를 기본으로 안내합니다.
(브라우저에 저장한 회로는 주소별로 따로 보관되니, 주소를 옮길 때는 `.json` 저장/열기를 이용하세요.)

설치나 회원가입이 필요 없습니다. 링크를 열면 처음 화면에서 실습할 장비를 세 가지 중 하나로 고릅니다.

- **공유압 회로** — 공압·유압 기호를 놓고 배선한 뒤 전기·PLC 제어까지 실행해 봅니다 (예제 22개).
- **PLC 래더** — 부품 없이 래더만 작성합니다. 실습실 PLC 트레이너처럼 생긴 입출력 판(누름버튼 P00000~7, 토글 스위치 P00008~F, 출력 램프 P00010~1F)으로 바로 확인합니다 (자기유지·타이머·플리커·카운터·정역 인터록 예제 5개).
- **컨베이어 시스템** — 자동화설비 기능사 스테이션을 PLC 래더로 운전해 공급·가공·분류를 확인합니다. 스테이션과 I/O 맵 26점이 갖춰진 상태에서 래더만 작성하면 됩니다. 예제는 실습 관례대로 **PB1 기본동작**(재료를 빼 두고 실린더 A~D만 한 사이클)과 **PB2 응용동작**(자동운전·재질별 분류)을 함께 담았습니다.

한 번 방문한 뒤에는 인터넷이 없어도 계속 쓸 수 있습니다(PWA 오프라인 지원). 새 버전이 나오면 자동으로 바뀌고, 툴바의 `최신 버전 갱신`으로 바로 갱신할 수도 있습니다.

> **PC/노트북 또는 태블릿(가로 모드)**: 가로 폭 1080px 이상 화면에서 동작합니다(iPad 9세대 이후·갤럭시 탭 S9 등 10인치급 태블릿 가로 모드 포함). 스마트폰과 태블릿 세로 모드에서는 안내 문구만 표시됩니다. 태블릿에서는 두 손가락 확대와 툴바의 다중 선택·복사·붙여넣기·부품 삭제 버튼을 쓸 수 있습니다.

## 이게 뭔가요?

특성화고·마이스터고에서 공유압(공압·유압)·전기 시퀀스 제어·PLC를 배울 때, 실제 실습 장비가 부족하거나 수업 시간이 짧아서 충분히 연습하기 어려운 경우가 많습니다. HYD는 이 문제를 브라우저만으로 해결하려는 프로젝트입니다.

- 화면에 **표준 스타일 기호**(밸브, 실린더, 릴레이, PLC 접점 등)로 회로도를 그립니다.
- **▶ 실행** 버튼을 누르면 그 회로가 실제로 어떻게 동작하는지 애니메이션으로 확인할 수 있습니다.
- 압력·전류 같은 물리량을 정밀 계산하는 공학용 시뮬레이터는 아닙니다. **"가압됐다/안 됐다", "접점이 붙었다/떨어졌다"** 같은 **논리·상태 흐름**을 보여주는 **교육용** 도구입니다.

기존 상용 실습 시뮬레이터(회로 중심 공학 시뮬레이션, 가상 실습장비 조작 등)의 좋은 점을 참고하되, 그 코드나 자산을 가져오지 않고 **처음부터 독자적으로 만들었습니다.** 이 부분의 근거와 검토 기록은 [ASSET_PROVENANCE.md](ASSET_PROVENANCE.md)에 자세히 남겨두었습니다.

## 주요 기능

| 영역 | 내용 |
|---|---|
| 작업 모드 | 처음 화면에서 공유압 회로·PLC 래더·컨베이어 시스템 중 고르기. 모드마다 작업 화면과 예제 목록이 따로이고, 다른 모드의 예제·파일을 열면 모드가 자동으로 바뀜 |
| 에디터 | 그리드 스냅, 직교 배선, 부품 배치/회전(버튼·R키)/삭제, 다중 선택(Shift+드래그)과 배선까지 함께 복사·붙여넣기(Ctrl+C/V), undo/redo, JSON 저장·불러오기, 인쇄용 SVG 내보내기(저장·열기·내보내기·브라우저 저장은 툴바의 **파일** 메뉴) |
| 공압 (20종) | 방향제어밸브(수동/롤러/파일럿/솔레노이드), 실린더, 속도제어·셔틀·2압·급속배기 밸브, 압력 스위치 등 |
| 유압 (19종) | 파워유닛, 릴리프·감압·체크·파일럿체크·유량조절 밸브, 4/2·4/3 밸브(클로즈드/탠덤/오픈 센터), 압력 시퀀스·카운터밸런스 밸브, 어큐뮬레이터, 실린더·모터 |
| 전기 (12종) | 릴레이·타이머·카운터·리밋스위치·솔레노이드 등, 전기공압 연동(A+B+A−B− 같은 자격증 유형 동작) |
| PLC | 교육용 래더(LD) 에디터 — 접점/코일/SET/RST/TON/TOFF/CTU/CTD, 입출력 매핑(다채널 부품은 채널 지정 — 방향·채널이 잘리지 않는 I/O 표, 입력은 파랑·출력은 초록 띠), 통전 모니터링 (표기는 XG5000(LS ELECTRIC) 관례를 참고했으며 비공식·비제휴) |
| PLC 래더 모드 | 부품 없이 래더만 — 입출력 판의 누름버튼(누르는 동안)·토글 스위치(클릭할 때마다)로 입력하고 출력 램프로 확인. 스위치를 누르면 실행이 함께 시작됨 |
| 실행 모드 | 연속동작 실행 + **구분동작 실행**(한 동작이 끝날 때마다 자동 정지, 사이클 완료 표시) |
| 장비 뷰 | 회로도 옆에 일러스트 실습장비 화면을 나란히 띄워 기호와 실물을 대응해서 학습. 리밋 스위치는 감지 대상 실린더의 후진단·전진단에 부착돼 눌리는 모습까지 표시 |
| 컨베이어 시스템 | 자동화설비 기능사(구 생산자동화) 컨베이어 공정 스테이션 — 매거진·공급/가공/이송 실린더·재질 판별·컨베이어·분류를 사진풍 장면에서 시뮬레이션, I/O 26점(입력 16+출력 10)을 래더로 제어. 실린더는 모두 복동(호스 2가닥)으로 표시. 공정 단계 표시줄, 공정을 따라가는 카메라(공급·가공·검출·분류 확대), 재생 속도 ×0.25/0.5/1 |
| 조작 패널 | 실습 장비 조작반처럼 PB1 초록·PB2 빨강·PB3 주황, PB4는 **Turn to Reset** 비상정지(누르면 잠기고 다시 누르면 풀림), 적·황·녹 시그널 램프, 처리 개수 7세그먼트 카운터. 공정이 비어 있을 때 PB1을 누르면 매거진 재료가 빠지고(기본동작은 재료 없이), PB2를 누르면 돌아옴. 매거진 칸에서 공급 순서를 보고 `금속`·`비금속`·`비우기`로 실행 중에도 재료를 넣고 뺌 |
| 예제 | 공압 기초·전기공압·유압·PLC·자격증 유형 22종 + PLC 래더 5종 + 컨베이어 1종, 모두 28종 내장 |
| 과제물 | 저장 시 "학습 활동 설명" 문장을 회로 구성에서 자동 작성(수정 가능) — 교사가 파일만 보고도 어떤 학습 활동인지 파악. 이름·학번 전용 필드를 두지 않고 서버로 전송하지 않음(자유 입력란에는 개인정보를 적지 않도록 안내) |
| 화면 | 도면지·실습실을 모티프로 한 차분한 화면, 두 줄로 정리한 툴바, 도면 기호 목록형 부품 팔레트, 키보드 초점 표시. 가로 1080px 화면에서도 툴바가 줄에 맞게 들어감 |
| 품질 | 자동 테스트 265개(핵심 동작 시나리오·솔버·PLC 스캐너·래더 모드·자동화설비 스테이션 기본/응용동작·문서 검증) |

## 인터넷 제한 환경에서의 교육용 로컬 실행

학교 네트워크에서 GitHub 또는 공식 배포 사이트에 접속하기 어렵거나 인터넷을 사용할 수 없는 경우, **교사와 학교는 비상업적 수업 목적으로 이 프로젝트의 변경되지 않은 사본을 학교가 관리하는 기기와 수업에 참여하는 학생의 기기에 복제하여 로컬에서 실행할 수 있습니다.**

수업에 필요한 범위에서 저장소·배포 파일의 다운로드, USB 등 저장매체를 통한 이전, 의존성 설치, 빌드 및 로컬 실행을 허용합니다. 수업 참여자만 접근할 수 있는 학교 내부망에서 실행할 수 있으나, **공개 인터넷 재호스팅, 불특정 다수에 대한 재배포, 유료 제공, 수정본 배포, 코드·자산의 별도 제품 전용은 허용되지 않습니다.** 사본에서 `LICENSE`와 `public/THIRD_PARTY_NOTICES.txt`를 삭제·변경해서는 안 됩니다. 상세한 허용 범위는 [LICENSE](LICENSE)의 "비상업적 교육용 오프라인 실행 허가" 절을 따릅니다.

```bash
npm install      # 의존성 설치 (Node.js 필요, 백엔드·DB 불필요)
npm run dev      # 로컬 실행 — http://localhost:5173
npm run build    # 정적 빌드 생성 (dist/ 를 학교 내부망 웹서버에 올려도 됩니다)
```

> 위 오프라인 실행 허가를 넘어서는 소스 수정·재배포·개발 기여는 저작자의 사전 서면 동의가 필요합니다([라이선스](#라이선스) 참고). `npm test`는 개발·검증용입니다.

## 중요한 고지사항

**이 소프트웨어는 교육용 논리/상태 시뮬레이션입니다.** 압력·전류의 수치를 정밀하게 계산하지 않으며(화면에 나오는 bar 수치는 압력 전파를 보여주기 위한 근사값입니다), **실제 설비를 선정하거나 압력을 설정하거나 안전을 검증하는 용도로 사용해서는 안 됩니다.**

**회로 기호는 ISO 1219 / KS B 0054 / IEC 60617 등에서 통용되는 표기 관례를 참고해 교육용으로 독자적으로 단순화한 것이며, 정식 표준 적합성이 인증된 것은 아닙니다.** 화면의 색상·애니메이션·강조 효과는 HYD가 시뮬레이션 상태를 보여주기 위해 추가한 것으로, 표준 기호 자체의 일부가 아닙니다.

**XG5000**은 LS ELECTRIC의 PLC 프로그래밍 소프트웨어 이름입니다. 이 프로젝트는 교육 목적으로 그 래더 표기 관례만 참고해 **독립적으로 구현**했으며, LS ELECTRIC과는 무관합니다. `.xgp` 등 XG5000 프로젝트 파일과 호환되지 않고, 로고 등 상표 자산도 사용하지 않습니다.

**자동화설비 스테이션**은 자동화설비 기능사(구 생산자동화 기능사) 실기의 일반적인 컨베이어 분류 공정을 교육용으로 **독자적으로 단순화**한 것입니다. **MPS®는 Festo AG & Co. KG의 등록상표입니다.
